# ☕ Java POO Portfolio

Bem-vindo ao meu portfólio de Programação Orientada a Objetos desenvolvido durante a disciplina de **Java** da **FIAP**.

Este repositório reúne todos os exercícios realizados ao longo do semestre, demonstrando minha evolução nos principais conceitos da Programação Orientada a Objetos (POO), desde a lógica de programação até o desenvolvimento de sistemas completos utilizando herança, polimorfismo, interfaces e coleções.

# ▶️ Como executar os projetos

1. Clone este repositório:

```bash
git clone https://github.com/pedroportugal01/java-poo-portfolio.git
```

2. Abra o projeto no IntelliJ IDEA.

3. Escolha o exercício desejado.

4. Execute a classe `Main.java` correspondente.
