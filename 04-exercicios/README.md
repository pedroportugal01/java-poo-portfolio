# 💻 Exercícios 04 - Sobrecarga de Métodos, Vetores e Associação entre Classes

## 📖 Descrição

Este projeto reúne exercícios desenvolvidos para aprofundar os conceitos da Programação Orientada a Objetos (POO) em Java.

Os exercícios exploram a sobrecarga de métodos, manipulação de vetores, associação entre objetos e simulações de situações do cotidiano, como o monitoramento de consumo de energia e o gerenciamento de um sistema de Bilhete Único.

---

# 🎯 Objetivos

- Praticar a sobrecarga de métodos (Method Overloading).
- Trabalhar com vetores para armazenamento de dados.
- Desenvolver aplicações utilizando múltiplas classes.
- Aplicar o conceito de associação entre objetos.
- Reforçar a lógica de programação utilizando Programação Orientada a Objetos.

---

# 📂 Exercícios

## Exercício 01 – Monitor de Energia

Sistema responsável por registrar o consumo de energia e calcular médias de consumo.

### Funcionalidades

- Registro diário de consumo.
- Cálculo da média geral de consumo.
- Cálculo da média em um intervalo específico de dias.

### Conceitos utilizados

- Vetores (Arrays)
- Sobrecarga de métodos
- Classes
- Objetos
- Estruturas de repetição

---

## Exercício 03 – Sistema de Bilhete Único

Simulação de um sistema de gerenciamento de Bilhete Único para transporte público.

### Funcionalidades

- Cadastro de usuários.
- Geração automática do número do bilhete.
- Associação entre usuário e bilhete.
- Recarga de saldo.
- Consulta de saldo.
- Pesquisa por CPF.
- Passagem pela catraca.
- Aplicação de desconto para estudantes e professores.

### Conceitos utilizados

- Associação entre classes
- Vetores de objetos
- Métodos
- Objetos
- Estruturas condicionais
- Estruturas de repetição
- Classe `Random`
- Classe `DecimalFormat`
