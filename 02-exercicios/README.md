# 💻 Exercícios 02 - Classes, Atributos e Métodos

## 📖 Descrição

Este projeto reúne exercícios desenvolvidos para praticar os conceitos iniciais da Programação Orientada a Objetos (POO) em Java.

Os exercícios abordam a criação de classes, atributos, métodos e objetos, além da interação com o usuário utilizando a classe `Scanner`.

---

# 🎯 Objetivos

- Praticar a criação de classes.
- Trabalhar com atributos e métodos.
- Instanciar objetos.
- Manipular dados informados pelo usuário.
- Aplicar cálculos utilizando métodos.
- Organizar o código em diferentes classes.

---

# 📂 Exercícios

## Exercício 01 – Conta Bancária

Simula uma conta bancária simples.

### Funcionalidades

- Cadastro do correntista.
- Geração automática do número da conta.
- Depósito.
- Saque.
- Exibição do saldo atualizado.

### Conceitos utilizados

- Classe
- Objeto
- Métodos
- Atributos
- Classe `Random`
- Classe `DecimalFormat`
- Entrada de dados com `Scanner`

---

## Exercício 02 – Paciente

Calcula a frequência cardíaca máxima e a frequência cardíaca alvo de um paciente com base em sua idade.

### Funcionalidades

- Cadastro do paciente.
- Cálculo da frequência máxima.
- Cálculo da frequência alvo.
- Exibição do intervalo ideal para exercícios físicos.

### Conceitos utilizados

- Classes
- Objetos
- Métodos com retorno
- Vetores (`double[]`)
- Entrada de dados com `Scanner`
