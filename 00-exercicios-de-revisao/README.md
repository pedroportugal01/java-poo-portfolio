# 📚 Exercícios de Revisão

## 📖 Descrição

Este projeto reúne exercícios de revisão desenvolvidos em Java com o objetivo de reforçar conceitos fundamentais da linguagem e da lógica de programação.

Os exercícios trabalham principalmente com estruturas de repetição, condicionais, entrada de dados pelo teclado e resolução de problemas utilizando a Sequência de Collatz (3n + 1).

---

## 🎯 Objetivos

- Revisar a sintaxe da linguagem Java.
- Praticar estruturas de repetição (`while`).
- Utilizar estruturas condicionais (`if` e `else`).
- Trabalhar com entrada de dados utilizando a classe `Scanner`.
- Desenvolver o raciocínio lógico por meio da Sequência de Collatz.

---

## 📂 Exercícios

### Exercício 01

Recebe um número inteiro positivo informado pelo usuário e imprime toda a Sequência de Collatz até que o valor seja igual a 1.

Exemplo:

```text
Entrada:
10

Saída:
10 5 16 8 4 2 1
```

---

### Exercício 02

Recebe um intervalo de números inteiros e calcula qual número desse intervalo gera a maior quantidade de elementos na Sequência de Collatz.

Ao final, exibe o maior número de iterações encontradas.
