# 👨‍🎓 Projeto Aluno

## 📖 Descrição

Este projeto foi desenvolvido para praticar os conceitos iniciais da Programação Orientada a Objetos (POO) em Java.

A aplicação permite cadastrar um aluno informando seu RM, nome, curso e duas notas. Após o cadastro, o sistema calcula automaticamente a média final e informa a situação do aluno (Aprovado ou Reprovado).

---

## 🎯 Objetivos

- Compreender a criação de classes e objetos.
- Trabalhar com atributos e métodos.
- Praticar a instanciação de objetos.
- Realizar cálculos utilizando métodos.
- Aplicar estruturas condicionais para tomada de decisão.

---

## ⚙️ Funcionalidades

- Cadastro de aluno
- Registro do RM
- Registro do nome
- Registro do curso
- Registro das notas
- Cálculo automático da média
- Exibição da situação do aluno

## ▶️ Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Execute a classe `Main.java`.
3. Informe os dados solicitados no terminal.
4. O sistema calculará a média e exibirá a situação do aluno.

---

## 💻 Exemplo de execução

```text

Curso: ADS
Nota 1: 8.0
Nota 2: 7.5

Média = 7.75
Situação = Aprovado
```
