# 💻 Exercícios 03 - Construtores, Static e Final

## 📖 Descrição

Este projeto reúne exercícios desenvolvidos para praticar conceitos importantes da Programação Orientada a Objetos (POO) em Java, com foco na utilização de construtores, atributos estáticos (`static`) e constantes (`final`).

Os exercícios simulam situações do cotidiano, como gerenciamento de produtos, controle de senhas de atendimento e utilização de um bilhete único para transporte público.

---

# 🎯 Objetivos

- Praticar a criação de construtores.
- Compreender o uso da palavra-chave `this`.
- Trabalhar com atributos e métodos.
- Utilizar atributos e métodos estáticos (`static`).
- Criar constantes utilizando `final`.
- Desenvolver aplicações simples utilizando Programação Orientada a Objetos.

---

# 📂 Exercícios

## Exercício 01 – Produto

Sistema simples para cadastro de produtos.

### Funcionalidades

- Cadastro do produto.
- Definição do valor inicial.
- Controle da quantidade em estoque.
- Aplicação de aumento percentual sobre o valor do produto.

### Conceitos utilizados

- Construtores
- Classes
- Objetos
- Métodos
- Palavra-chave `this`

---

## Exercício 02 – Senha de Atendimento

Simula um sistema de geração automática de senhas para atendimento.

### Funcionalidades

- Cadastro de pacientes.
- Geração automática de senha.
- Controle sequencial das senhas.
- Exibição dos dados do paciente.

### Conceitos utilizados

- Atributos estáticos (`static`)
- Construtores
- Objetos
- Métodos

---

## Exercício 03 – Bilhete Único

Simula o funcionamento de um cartão de transporte público.

### Funcionalidades

- Cadastro do usuário.
- Definição do tipo de tarifa.
- Recarga do cartão.
- Consulta de saldo.
- Passagem pela catraca.
- Aplicação de desconto para estudantes e professores.
- Controle de saldo disponível.

### Conceitos utilizados

- Construtores
- Constantes (`final`)
- Atributos estáticos
- Métodos
- Estruturas condicionais
- Estruturas de repetição
- Menu interativo
- Classe `Random`
