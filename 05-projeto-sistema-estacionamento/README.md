# 🚗 Exercício 05 - Sistema de Estacionamento ParkEasy

## 📖 Descrição

Este projeto consiste em um sistema simplificado de gerenciamento de estacionamento desenvolvido em Java utilizando os conceitos da Programação Orientada a Objetos (POO).

A aplicação permite registrar a entrada e saída de veículos, calcular automaticamente o valor da permanência com base no tempo estacionado e controlar a receita total do estacionamento.

---

# 🎯 Objetivos

- Aplicar os conceitos de Programação Orientada a Objetos.
- Trabalhar com múltiplas classes relacionadas.
- Utilizar vetores para armazenamento de objetos.
- Manipular datas e horários utilizando a API `java.time`.
- Desenvolver um sistema de menu interativo.

---

# ⚙️ Funcionalidades

- Cadastro de proprietários.
- Cadastro de veículos.
- Registro de entrada de veículos.
- Registro de saída.
- Cálculo automático do valor da permanência.
- Consulta de veículos estacionados.
- Cálculo da receita total do estacionamento.

# ▶️ Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Execute a classe `Main.java`.
3. Utilize o menu para registrar entradas e saídas de veículos.
4. Consulte os veículos estacionados ou visualize a receita acumulada.
